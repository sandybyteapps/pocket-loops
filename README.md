# Pocket Loops website

Static source for a Sandybyte-branded Pocket Loops home, support and privacy site. No build step, scripts or analytics. The mark and generated `sandybyte.css` are copied from the SandybyteBrandKit in `00_sandybyte`; retain their original colours and proportions.

Sandybyte app websites use a separate public GitHub Pages repository for each app. The Pocket Loops site is intended for `sandybyteapps/pocket-loops`:

- `https://sandybyteapps.github.io/pocket-loops/`
- `https://sandybyteapps.github.io/pocket-loops/support/`
- `https://sandybyteapps.github.io/pocket-loops/privacy/`

To publish updates, copy this folder's contents into a clone of the Pages repository, commit and push to its publishing branch. Verify the public pages after changes. The privacy wording must be kept consistent with the app's actual AdMob/UMP configuration and App Privacy disclosures. The support address is `support@sandybyte.com`.
